MCP server for social media and email

Run your social media from ChatGPT, Claude or Gemini

Connect your AI app to Postfjord and ask for the week's posts, the reply to a DM or this month's newsletter. It writes them in your brand voice, puts them in your calendar and waits for your yes.

https://mcp.postfjord.com/mcp

Paste the address in your AI app and sign in. Nothing to install, no key to paste.

Ask the way you would ask a person

Your AI app reads what it needs from your workspace: your brand voice, your calendar, your contacts and how your posts did. Then it does the work and shows you the result.

"Plan next week: three posts for Instagram and Facebook, Tuesday, Thursday and Saturday at 9 New York time. Leave them as drafts."

"Which posts did best last month? Plan three more like them."

"Who is waiting for an answer in the inbox? Draft a reply to each and show me before you send."

"DM everyone who comments CLASS the booking link."

"Email the best post to my list, with a button to book."

"Did yesterday's post go out? If something failed, tell me why."

Connect in two minutes

The first time, your browser opens Postfjord. Sign in, pick the workspace and what the app may do, and press Allow. You need to own the workspace, on the Solo plan or bigger.

ChatGPT

Open Plugins and press +. Pick Add custom MCP server (turn on developer mode in the settings if you do not see it), paste the address, choose OAuth and create it.

ChatGPT and Postfjord

Claude

On claude.ai, Claude Desktop or the phone app: open Customize, then Connectors. Press Add custom connector, paste the address, press Add and then Connect.

Claude and Postfjord

Gemini

In the Gemini app: Settings, Connected Apps, Add a custom app. In Gemini CLI, add this under mcpServers in ~/.gemini/settings.json, then run /mcp auth postfjord.

"postfjord": { "httpUrl": "https://mcp.postfjord.com/mcp" }

Claude Code

The server and the Postfjord skill in one install:

claude plugin marketplace add Rustysama/postfjord-agents
claude plugin install postfjord@postfjord

Cursor, VS Code, Codex and others

Any app that speaks MCP over HTTP can use the same address. Apps that cannot open a browser use a key from Postfjord, Settings, Apps, sent as Authorization: Bearer pf_live_....

You choose how far it goes

You pick a level for every connection when you sign in, and you can revoke it any time in Postfjord under Settings, Apps.

Read onlyLooks at your calendar, numbers, inbox and email reports. Changes nothing.
Drafts onlyWrites drafts, adds pictures and builds automations that stay paused. Nothing it makes can go out.
Schedule and publishCan also put a time on a post, publish, send an email or a reply, and switch an automation on.

No tool reaches billing, team members, API keys or your connected social accounts, and none deletes a post that already went out. Each tool tells the app whether it changes something or reaches the public, so apps like Claude ask you first. Tools that send something take an idempotency key, so a retry never posts twice.

Questions

What does the Postfjord MCP server do?

It connects your AI app to your Postfjord workspace. The app can then read your calendar, brand voice and numbers, write and schedule posts, answer DMs and comments, draft emails and set up automations, as far as you allow at sign in.

Will my AI app post without asking me?

Only if you allow it. Pick Read only or Drafts only and nothing can go out. With Schedule and publish, apps like Claude still ask before each call that reaches the public, because every tool says what it does.

What does it cost?

The MCP server comes with the Solo, Studio and Agency plans. See prices. The local server and the skill in this repository are MIT licensed.

Do I need to install anything?

No. Paste the address into your AI app and sign in. The local server is there for apps that start MCP servers themselves.

Where is my data kept?

Postfjord is run from Sweden and keeps its data in the EU. The server sees only the arguments of each call, never the rest of your conversation. Read the privacy policy.

Can I build my own agent on it?

Yes. Any agent that speaks MCP can sign in with OAuth, and anything that calls a REST API can use a key. See the developer docs and the agents that work with Postfjord.
